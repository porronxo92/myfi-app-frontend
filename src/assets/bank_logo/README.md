# Logos de Bancos

Esta carpeta contiene los logos de los bancos soportados por la aplicación.

## Formato
- Los archivos deben ser SVG
- Nombre del archivo: nombre del banco en minúsculas, con espacios reemplazados por guiones bajos (_)
- Dimensiones recomendadas: 48x48 píxeles (el contenedor se ajustará automáticamente)

## Logo por defecto

Si no se encuentra el logo de un banco, se utilizará automáticamente `default.svg`, que muestra un ícono genérico de banco.

## Cómo agregar un nuevo logo

1. Crear un archivo SVG con el logo del banco
2. Nombrar el archivo según el nombre del banco (minúsculas, sin espacios)
3. Guardar el archivo en esta carpeta
4. El sistema lo detectará automáticamente
